# Sinov maydonçasi

Python kodini şu yerda sinab köring. Kodni işga tuşiriş uçun **Ctrl + Enter** ni, Mac da esa **⌘ + Enter** ni bosing. **Töxtatiş** tugmasi Python seansini yangidan boşlaydi.

<ClientOnly><PythonPlayground /></ClientOnly>

## Muharrir qanday işlaydi {#good-to-know}

- Har safar kod yangidan bajariladi. Oldingi özgaruvçilar saqlanmaydi.
- Kod `input()` ni çaqirganda muharrir savolni körsatadi. Javob berilgandan söng dastur hozirgaça kiritilgan javoblar bilan boşidan bajariladi.
- `collections`, `heapq`, `bisect` va `itertools` singari standart modullar mavjud.
- Oddiy bajariliş 15 soniyadan söng töxtatiladi. Paketlarni yuklaş uçun köproq vaqt beriladi.
- Kod brauzer işçisida [Pyodide](https://pyodide.org/en/stable/usage/webworker.html) orqali bajariladi. Fayl va tarmoq amallari şu muhit imkoniyatlariga boğliq.
